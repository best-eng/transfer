# 🚗 Трансфер-бот Йошкар-Ола ↔ Казань

## Структура репозитория

```
transfer_bot/
├── transfer_bot.py      # основной код бота
├── requirements.txt     # зависимости
├── Procfile             # команда запуска для Railway
└── .gitignore
```

## Деплой на Railway (пошагово)

### 1. Создайте репозиторий на GitHub
Загрузите все 4 файла из этого архива.

### 2. Подключите Railway
- Зайдите на railway.app → Log in with GitHub
- New Project → Deploy from GitHub repo → выберите репозиторий

### 3. Добавьте переменные окружения
В панели Railway: ваш сервис → вкладка **Variables**

| Key             | Value                        |
|-----------------|------------------------------|
| `BOT_TOKEN`     | токен от @BotFather           |
| `ADMIN_CHAT_ID` | ваш chat_id (узнать у @userinfobot) |

> Если диспетчеров несколько — перечислите через запятую: `111111,222222`

### 4. Убедитесь что запустился
Вкладка Deployments → View logs → должно быть:
```
Бот запущен...
```

## Обновление
Просто сделайте `git push` — Railway автоматически перезапустит бота.

## Команды бота

| Команда   | Действие                  |
|-----------|---------------------------|
| `/start`  | Начать оформление заявки  |
| `/cancel` | Отменить текущий диалог   |
